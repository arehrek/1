Teoria: Zaokrąglanie narożników obszarów bloków (np. DIV)

Poniższa tabela przedstawia składnię CSS dla poszczególnych narożników elementów blokowych:

Umiejscowienie narożnika Składnia teoretyczna reguły CSS
Zaokrąglenie górnego-lewego narożnika: selektor { border-top-left-radius: zaokrąglenie }
Zaokrąglenie górnego-prawego narożnika: selektor { border-top-right-radius: zaokrąglenie }
Zaokrąglenie dolnego-prawego narożnika: selektor { border-bottom-right-radius: zaokrąglenie }
Zaokrąglenie dolnego-lewego narożnika: selektor { border-bottom-left-radius: zaokrąglenie }

Zastosowanie oraz uwagi dotyczące zaokrąglania narożników

We wszystkich przypadkach selektorem może być dowolny znacznik, np.:

  • p – akapit
  • h1 – nagłówek
  • div – blok

Natomiast wartość "zaokrąglenie" określa promień wyrażony w jednostkach długości (np. px, em) albo w procentach (względem obszaru obramowania - zobacz: Model pudełkowy). Możliwe jest tutaj podanie:

  • jednej wartości - zaokrąglenie symetryczne
  • dwóch wartości - pierwsza określa poziomy promień ćwiartki elipsy zaokrąglenia, a druga - pionowy

Zaokrąglone narożniki to bardzo ciekawy efekt wizualny, który może zwiększyć estetykę strony. Co ciekawe, element wcale nie musi mieć obramowania, aby miał zaokrąglone narożniki. Wystarczy, jeśli będzie miał ustalone jakieś tło, aby efekt był widoczny na ekranie.

Ale uwaga: tekst wewnątrz elementu nie zostanie zawinięty do zaokrąglonych rogów. Jeśli promień zaokrąglenia będzie zbyt duży, tekst wyjdzie na zewnątrz.

Przykład z instrukcji

border-top-right-radius: 10px;

Teoria: Centrowanie bloku DIV

Aby poprawnie wycentrować element blokowy (taki jak DIV) w poziomie względem jego rodzica, w definicji CSS danego bloku należy wpisać automatyczne marginesy boczne:

margin-left: auto;
margin-right: auto;

Uwaga: Do poprawnego działania centrowania za pomocą marginesów, wycentrowany blok DIV powinien mieć również określoną szerokość (np. width: 50%; lub width: 400px;), w przeciwnym razie domyślnie zajmie 100% dostępnej szerokości i efekt centrowania nie będzie widoczny.
