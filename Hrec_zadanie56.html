1) Składnia teoretyczna definiowania klasy

selektor.klasa { cecha: wartość }

2) Podaj opis dla Klasa "cecha" oraz "wartość"

Klasa to wartość atrybutu class="..." nadanego selektorowi z poziomu języka (X)HTML.

"cecha" oraz "wartość" określają atrybuty elementu nadane poprzez style (właściwość CSS i przypisaną jej wartość podkręcającą wygląd).

3) Jaki znacznik może być selektorem? Trzy przykłady selektorów dla klas (ze znaczeniem)

Selektorem może być dowolny znacznik języka HTML. Przykłady:

  • p → akapit (tekst blokowy),
  • h1 → tytuł / nagłówek najwyższego stopnia,
  • td → komórka tabeli.

4) Podaj uwagi na temat nazwy klas

Nazwą może być dowolny pojedynczy wyraz, nie może on zawierać znaków:

  1. spacji
  2. kropki
  3. przecinka
  4. dwukropka
  5. pytajnika
  6. nawiasów
  7. znaku równości
  8. plusa itp.

Może zawierać:

  1. litery (A-Z, a-z)
  2. cyfry (0-9)
  3. myślniki ("-")
  4. podkreślniki ("_") (Lepiej nie używać polskich liter)

Nazwa nie może zaczynać się od cyfry ani myślnika.

Gdy chcemy użyć znaków "zakazanych" znaków, należy w deklaracji klasy poprzedzić je odwróconym ukośnikiem "\", np. reguła: selektor.B\&W\? { cecha: wartość } odpowiada klasie: class="B&W?".

5) Jakie jest zastosowanie klas?

Deklaracja klasy jest przydatna szczególnie, jeśli na wielu stronach serwisu znajdują się elementy mające takie samo formatowanie, a dodatkowo nie można dla nich posłużyć się selektorem typu, ponieważ na stronie znajdują się inne znaczniki tego samego rodzaju co wybrany element, ale nie chcemy, aby i one otrzymały takie samo formatowanie.

6) Kiedy ma zastosowanie lista klas?

Lista klas ma zastosowanie, jeśli chcemy do pojedynczego elementu przypisać kilka różnych, niezależnych klas CSS jednocześnie, łącząc ich właściwości formatowania w jednym znaczniku HTML.

7) Składnia teoretyczna listy klasy oraz uwagi

<selektor class="klasa1 klasa2 klasa3...">...</selektor>

Uwagi:

  • Klasy: klasa1, klasa2, klasa3 muszą być zdeklarowane w wewnętrznym, zewnętrznym lub importowanym arkuszu stylów.
  • Kolejność wpisywania nazw klas w wartości atrybutu class="..." nie ma znaczenia na ostateczny sposób formatowania elementu. Jeżeli kilka przypisanych klas odnosi się do tej samej własności, o wyniku decyduje zasada kaskadowości (kolejność definicji w arkuszu CSS).

8) Czym są podzbiory klas. Składnia teoretyczna listy klasy

Istnieje możliwość określenia tzw. podzbioru klas, czyli podania, jakie klasy musi mieć jednocześnie przypisane element, aby wybrana reguła CSS miała do niego zastosowanie. Na przykład po wpisaniu składni:

selektor.klasa1.klasa3 { cecha: wartość }

Zmieniony zostanie sposób formatowania elementu wywołanego jako:

<selektor class="klasa1 klasa2 klasa3">...</selektor>

Kolejność podawania klas – zarówno w regule CSS, jak i w wartości atrybutu class="..." – nie ma znaczenia.

9) Co jest sygnałem (przesłanką), że należy zastosować klasy?

  • Jeśli jakiś element, o specyficznym rodzaju formatowania, występuje przynajmniej raz na niektórych stronach Twojego serwisu (może to być np. główny tytuł strony), jest to znak, że dobrze byłoby umieścić w zewnętrznym arkuszu stylów deklarację jego klasy. Dzięki temu, jeśli później zdecydujemy się zmienić jego formatowanie, nie będziemy musieli modyfikować każdej ze stron, a jedynie zewnętrzny arkusz.

10) Kiedy i z jakiego powodu powinny być planowane klasy dla wykonywanej strony?

  • Już na początkowym etapie projektowania serwisu, dobrze jest dokładnie obmyślić, jakie klasy mogą okazać się użyteczne. Im więcej deklaracji klas – odnoszących się do powtarzalnych elementów – umieścisz w zewnętrznym arkuszu stylów, tym szybciej przebiegnie późniejsza ewentualna modyfikacja stron!

11) Jaki jest cel stosowania komentarzy podczas definiowania klas?

  • Dobrym pomysłem jest również wstawianie komentarza przed każdą deklaracją klasy w arkuszu (znaki: /* ... */), w którym opisuje się jej przeznaczenie. Po jakimś czasie w Twoim arkuszu stylów może znaleźć się tyle klas, że zapomnisz, do jakich elementów się one odnosiły. Wtedy właśnie bardzo przydatny może się okazać wpisany wcześniej komentarz.

12) Podaj konkretny przykład definiowania klasy oraz jej użycia (wywołanie)

Definicja w arkuszu styli:

p.przyklad_klasa { color: red; }

Wywołanie w kodzie HTML:

<p class="przyklad_klasa">To jest akapit.</p>

13) Omów klasę odnoszącą się tylko do jednego selektora wraz z przykładem

Klasa odnosząca się tylko do jednego selektora to klasa NIEUNIWERSALNA. Podobnie jak w przypadku identyfikatora, tak zdefiniowana klasa może zostać użyta tylko w tym selektorze (znaczniku), do którego została bezpośrednio przypisana w CSS.

Przykład 1: Zdefiniowanie oraz użycie klasy NIEUNIWERSALNEJ dla znacznika <p>

Definicja arkusza styli:

p.moja {
  color: green;
  font-size: 14pt;
}

Wywołanie (fragment kodu HTML):

<p class="moja">Treść akapitu</p>

Przykład 2:

Plik *.CSS:

p.przyklad_klasa { color: red; }

Fragment kodu HTML → wywołanie klasy:

<p class="przyklad_klasa">To jest akapit.</p>

14) Jaki jest cel stosowania klasy uniwersalnej. Jakie jest znaczenie znaku „*” oraz kiedy można nie stosować tego znaku. Podaj przykład

Klasa uniwersalna ma na celu umożliwienie formatowania różnych typów znaczników HTML tą samą klasą, gdy podczas projektowania nie wiemy jeszcze, do jakich dokładnie elementów jej użyjemy.

Znaczenie znaku * to selektor uniwersalny (odnosi się do wszystkiego). Znak ten można całkowicie pominąć – zapis rozpoczynający się bezpośrednio od kropki (np. .nazwa) jest domyślnie traktowany jako uniwersalny.

Przykład 1 (z gwiazdką i bez):

*.przyklad_uniwersalna { color: red; }
.przyklad_uniwersalna { font-size: 12pt; color: red; }

Przykład 2 (Definicja i wywołanie wielokrotne):

Definicja:

.moja {
  color: red;
  font-size: 12pt;
  font-style: italic;
}

Wywołanie:

<p class="moja">Przykład akapitu z określoną klasą</p>
<h1 class="moja">Przykład nagłówka z określoną klasą</h1>

Przykład 3 (Nadpisywanie i współpraca z selektorami typu):

Kod arkusza CSS:

p {
  font-size: 14pt;
  color: green;
}
.moja {
  font-style: italic;
  font-size: 20pt;
  color: red;
}

Kod fragmentu HTML:

<p>Blok tekstu o kolorze zielonym i czcionce 14pt</p>
<p class="moja">Blok tekstu, w którym użyłem klasy o nazwie .moja</p>
<p>Blok tekstu o kolorze zielonym i czcionce 14pt</p>
<ol class="moja">
  <li>lista, w której użyłem klasy o nazwie .moja</li>
  <li>lista, w której użyłem klasy o nazwie .moja</li>
</ol>
