1) Co to są pseudoklasy?

CSS przewiduje kilka ściśle określonych klas pozwalających na formatowanie niektórych elementów dokumentu – są to właśnie Pseudoklasy.

2) Uwaga dotycząca dwukropka

Szalenie istotnym elementem w tej konstrukcji jest dwukropek występujący pomiędzy selektorem a nazwą klasy (np. A:hover).

3) Tabela opisująca pseudoklasy

Pseudoklasa Opis działania i odpowiedzialność
A:link Odpowiada za wygląd hiperłącza, jeżeli nie zostało ono jeszcze odwiedzone.
A:visited Odpowiada za formatowanie hiperłącza już odwiedzonego.
A:hover Odpowiada za zmiany pewnych elementów po najechaniu na nie urządzeniem wskazującym (np. myszą), np. odsyłacz, nad którym zatrzymano kursor lub element blokowy DIV.
A:active Pozwala nadać dowolne formatowanie elementowi po nakierowaniu na niego wskaźnika myszy i wciśnięciu przycisku, ale przed jego zwolnieniem (odsyłacz aktywny → kliknięty).
A:focus Stosowany, jeżeli chcemy, by właśnie wyświetlany odsyłacz z menu był formatowany innym kolorem. Odsyłacz posiadający tzw. fokus zaznaczony przy poruszaniu się po dokumencie przy pomocy klawisza tabulacji: naciśnięcie w tym momencie klawisza ENTER spowoduje taką reakcję przeglądarki, jakby dany odsyłacz został kliknięty.
:lang Formatowanie wielojęzykowych dokumentów.
:first-child Umożliwia określenie formatowania dla pierwszego dziecka (elementu potomnego) wybranego elementu.

4) Zastosowanie pseudoklasy :active

Pseudoklasy :active można używać jako:

  1. Uzupełnienia definicji odnośników.
  2. Elementu poprawiającego czytelność formularzy.

5) Przykłady (trzy) kodów definiowania pseudoklas (wraz z tematem)

Przykład 1

Temat: Arkusz wykorzystujący :link oraz :visited pseudoklasy w połączeniu z selektorem A. Przykładowa definicja sformatuje odnośnik za pomocą koloru czerwonego i po wybraniu taki odnośnik będzie miał kolor zielony.

A:link {
    color: red;
}
A:visited {
    color: green;
}

Przykład 2

Temat: Formatowanie wyglądu wszystkich odnośników w dokumencie XHTML/HTML.

A /* Definicja odsyłacza podstawowego */ {
    font-size: 12pt;
    text-decoration: none;
}
A:link {
    color: navy;
}
A:visited {
    color: green;
}
A:hover {
    color: red;
    text-decoration: underline;
}

Przykład 3

Temat: Zastosowanie :focus

A:focus {
    color: brown;
}
